# 03 — AI Agents

This folder is for your first AI agents. An agent is a program that does more than answer once. It looks at a goal, decides on a next step, takes that step, looks at the result, and repeats until the task is done or it should stop.

This is a practice space alongside Ed Donner's course. It does not replace the course materials.

## What you will learn

- The agent loop: reason, act, then observe the result.
- The difference between a one-shot model call and an agent that can take several steps.
- How an agent keeps track of the conversation and the steps it has already taken.
- Why an agent needs a stopping rule so it does not run forever.
- How to describe an agent's job in plain language before you write the code.

## What you will practise

- A tiny agent with one clear job, such as answering a question using a short set of notes you provide.
- Logging each step the agent takes so you can read what it decided and why.
- Changing the instructions and watching how the agent's behavior changes.

## How to use this folder

Start with the simplest loop you can explain out loud. Add tools and extra agents in the later folders. Name each exercise after the idea it demonstrates, for example `simple_agent_loop.py`.
