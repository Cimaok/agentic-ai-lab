# 01 — Python Foundations

This folder is for the Python you need before building AI agents. Agentic systems are mostly Python programs that call models, pass data around, and handle errors. Strong basics make the later lessons easier.

This is a practice space alongside Ed Donner's course. It does not replace the course materials.

## What you will learn

- How to write clear Python scripts and functions.
- How data types, lists, dictionaries, and loops work in real programs.
- How to read and write files, including JSON, which agents use to pass structured data.
- How virtual environments and `requirements.txt` keep project packages separate.
- How to catch and understand errors instead of guessing what went wrong.

## What you will practise

- Small scripts that take an input, transform it, and print or save a result.
- Functions with clear inputs and outputs, the same shape tool functions will have later.
- Reading configuration and sample data from files.
- Running code from the terminal and from Cursor.

## How to use this folder

Add one file per exercise as you follow a lesson, for example `variables_and_types.py` or `read_json.py`. Keep each exercise small enough to finish in one sitting. Short comments at the top of a file are enough to remind you what the exercise was for.
