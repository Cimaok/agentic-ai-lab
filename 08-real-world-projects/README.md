# 08 — Real-World Projects

This folder is for larger practice projects after the earlier sections feel familiar. A project here should solve a small, real task from start to finish: a clear input, an agent or workflow that does the work, and a result you can check.

This is a practice space alongside Ed Donner's course. It does not replace the course materials. Do not start a project here until you have practised the idea it depends on in an earlier folder.

## What you will learn

- How to turn a vague idea into a small project with a defined user and outcome.
- How to choose the simplest design that works: one model call, one agent, or a short workflow.
- How to keep secrets, sample data, and dependencies organized.
- How to write a short project README so you can explain what you built later.
- How to judge whether the project actually did the job, not only whether the code ran.

## What you will practise

- Scoping a project to something you can finish, such as a research helper, a document summarizer, or a small automation for a repeated task.
- Reusing patterns from folders 01–07 instead of inventing a new structure each time.
- Writing down what worked, what failed, and what you would change.

## How to use this folder

Give each project its own subfolder with a README that states the goal, how to run it, and what you learned. Leave the project empty until you are ready to build it. Add any new Python packages to the root `requirements.txt` only when that project needs them.
